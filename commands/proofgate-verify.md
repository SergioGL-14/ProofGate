description: Verify existing work with ProofGate without editing
---

Load the `proofgate` skill and execute the `verify` operation.

Use `$ARGUMENTS` as the user's verification target and optional intensity or
profile selection. Do not modify tracked project content or edit any file to
make a check pass. Relevant gates may create their ordinary ignored build
artifacts. Obtain explicit authorization before installing a missing tool or
dependency, prefer an isolated installation, and report it. A request to fix a
failure must use `build` instead.
