# Code of Conduct

ProofGate welcomes technical disagreement, careful criticism, and evidence that
invalidates an existing claim. Participation must remain respectful,
professional, and focused on the work.

## Expected behavior

- Discuss ideas and evidence without attacking people.
- State uncertainty, conflicts of interest, and relevant limitations.
- Respect privacy; do not publish credentials, private repository details, or
  personal information.
- Accept corrections when stronger evidence is produced.

Harassment, discrimination, threats, deliberate exposure of private
information, and sustained disruptive behavior are not acceptable.

## Enforcement

Maintainers may edit or remove content, close interactions, or restrict
participation when necessary to protect contributors and the project. Report
abusive GitHub content through GitHub's private reporting controls. Report a
ProofGate security vulnerability through the private process in
[`SECURITY.md`](SECURITY.md); do not disclose exploit details in a public
conduct report.

This policy applies to the repository and to public interactions made on
behalf of ProofGate.
